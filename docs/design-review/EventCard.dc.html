The event card, taken apart

Same quiz night, same four facts, same 340 px width. The card on the right holds all of it in 158 px instead of 300, which is what a listing card of four short facts should cost.

  • The date is stated twice, 60 px apart.
  • "Pub kviz" is the fallback title, so neighbouring cards read identically.
  • The venue, the one thing that identifies this card, is the smallest grey line.

  • Date, venue, city and mark sit on one line instead of four stacked blocks.
  • The date block is the only date, and it turns accent for danas or sutra.
  • Chips never wrap and titles clamp at two lines, so one long name cannot stretch its neighbours.
  • Padding drops 22 to 18, the mark 56 to 40, the numeral 28 to 24.

The remaining slack in a short card is about 29 px, because cards in a row still stretch to the tallest. It reads as padding at this height, which it did not at 300 px.
