Why not one face for both

Cobe Heavy is a poster weight. It carries a headline across a room, which is exactly what it does in the projected quiz. At 15 px in a paragraph it is unreadable, and shipping a second cut for body copy would roughly double the font payload for a job the system stack already does well.

Where the line falls

Cobe takes h1, h2, the hero and any figure a visitor is meant to register: counts, dates, times, prices. Card titles, body copy, labels, chips and form fields stay on the system stack, which resolves to the reader's own interface face.

Fallback

Anton, then Impact, then the system stack. The same chain the presentation mode already uses, so a missing font degrades the site the way it degrades the projection.
