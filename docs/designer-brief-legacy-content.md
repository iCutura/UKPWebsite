**Purpose of this document:** we are replacing the current website at kvizovi.hr with a new one. This is a complete inventory of what the current site contains: which pages exist and what is written on each of them, reproduced verbatim in Croatian. It is source material for the new site's content. It says nothing about how the new site should look; that is your job.

**Language:** the whole site is in Croatian only.

**What was extracted:** every page's title, meta description, headings and body copy, plus the numbers shown in counters, the links behind buttons, the contact and company details, and a description of the imagery present on each page (so you know what visual material exists, not how it was laid out). # Part 2: live content on the new site

The old site's biggest weakness was that the locations page was typed in by hand in 2023 and never updated. The new site will not repeat that. Everything about where and when quizzes happen will come from the same system that runs the UKP Quiz mobile apps, and it will always be current. This part describes what that content is, with real examples, so you know what the pages have to carry.

Three kinds of live content plus one action:

1. **News** (novosti)
2. **Locations** (lokacije), each with its **upcoming events** (događaji / termini)
3. **Event registration** (prijava ekipe na kviz)

The reference for all of this is the UKP Quiz app; the website shows the same data to people who do not have the app installed.

## Scale, so you can plan for real quantities

| What | How many today |
|------|----------------|
| Locations | 137, in about 90 towns across Croatia and Bosnia and Herzegovina, from Umag to Dubrovnik, Bihać to Sarajevo |
| Locations in Zagreb alone | 27 |
| Upcoming events at any moment | typically 15 to 40 in the next two weeks; each location usually has one |
| News items | few, published every couple of weeks or around big events |

Locations are added and retired all the time, so the site cannot assume a fixed list or a fixed number of cities.

## 1. News (novosti)

## 2. Locations (lokacije)

**What a "location" is.** A location is a *quiz series*, not just a bar. The same venue can host quizzes on several weekdays, and each weekday is its own location with its own name, for example "Zug - Ponedjeljkom", "Zug - Utorkom" and "Zug - Srijedom" are three locations at the venue Caffe bar Zug in Zagreb. "Campus - Ponedjeljkom / Srijedom / Četvrtkom" in Osijek and "Gossip Ponedjeljkom / Srijedom / Četvrtkom" in Varaždin are the same pattern. Most locations, though, are simply "Venue - Town", such as "Zeppelin pub - Bjelovar".

Each location carries:

| Field | Always present | Example |
|-------|----------------|---------|
| Name (series name) | yes | Star Caffe - Daruvar |
| Venue name | yes | Star Caffe |
| Town | yes | Daruvar |
| Address | usually | Ul. Stjepana Radića 2, 43500, Daruvar |
| Map coordinates | usually | 45.5878, 17.2229 |
| Venue logo | usually | small square image |
| Photo of the venue or a quiz night | about half | one image |
| Description (free text from the team) | sometimes | Info i rezervacije: +385919243395 (Renato) |
| Usual start time | usually | 19:00 |
| Usual maximum number of teams | sometimes | 9 |
| Usual maximum players per team | sometimes | 5 |
| Usual fee | sometimes | 10 € po ekipi, or per person; often none is recorded |
| WhatsApp community link | some | a link to the location's WhatsApp group where the host posts updates |
| Number of upcoming events | yes | 1 |
| Next event date and time | when scheduled | 17. 9. 2026. 19:00 |
| List of upcoming events | yes, can be empty | see next section |

Content the pages need: a way to find a location by town (visitors think "kviz u Karlovcu", not by bar name), a list of all locations, and a page per location showing the fields above and its upcoming events. A location can have **no upcoming event** at all, which happens a lot outside the season and over summer; that state needs honest wording rather than an empty gap.

## 4. Event registration (prijava ekipe)

Visitors will be able to register a team for an upcoming event directly from the website, the same thing app users do today. A registration consists of:

| Field | Required | Notes |
|-------|----------|-------|
| Team name | yes | the name the team plays under; teams keep the same name across quizzes and leagues |
| Contact name | yes | the team captain |
| Phone | one of phone or email | |
| Email | one of phone or email | |
| Number of players | no | limited by the event's maximum players per team |
| Note to the host | no | free text, for example "dolazimo nas 6, može li iznimno?" |

After submitting, the registration has a status the team can see:

- **Na čekanju (pending)**, when the event requires host approval
- **Potvrđeno (confirmed)**
- **Odbijeno (rejected)**, by the host, for example when the event is full
- **Otkazano (cancelled)**, by the team

Things the registration flow must be able to say:

- the event is **full** (no spots remaining), so registration is not possible
- the **registration deadline has passed**
- the event is **cancelled**
- the registration was received and is **confirmed**, or is **waiting for approval**
- a team can **cancel** its registration and is asked for a reason from a fixed list: Konflikt u rasporedu, Tim nije dostupan, Pronašli smo drugi događaj, Promjena planova, Financijski razlozi, Ostalo
